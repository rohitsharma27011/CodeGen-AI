# CodeGen-AI

CodeGen-AI is an AI-powered full-stack application builder that generates, edits, and deploys applications from natural language prompts.

## Features

- AI-powered code generation
- Full-stack application scaffolding
- Conversational project editing
- Real-time code updates

## Tech Stack

### Backend
- Java
- Spring Boot
- PostgreSQL

### Frontend
- React
- TypeScript
- Tailwind CSS

### AI
- OpenAI / Gemini
